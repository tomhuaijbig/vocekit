# vocekit 测试说明

## 开始使用

1. 解压整个压缩包，不要只单独运行程序文件。
2. 双击 `vocekit.exe`。程序启动后会在系统托盘后台运行，并打开主界面。
3. 首次使用请打开“设置 -> 接口”，填写测试人员自己的接口密钥。
4. 在“设置 -> 接口”选择百度语音识别或讯飞语音听写。
5. 在“设置 -> 快捷键”查看或修改各功能快捷键。

测试包不包含开发者的接口密钥、录音和历史记录。没有填写接口密钥时，对应功能会提示配置不完整。

Windows 可能因为程序暂未签名而显示安全提醒。请确认压缩包来源可信后，再选择继续运行。

## 建议测试内容

- 程序关闭主窗口后是否仍在托盘运行，托盘菜单能否正常打开和退出。
- 听写、翻译、问答和自定义功能的快捷键是否正常。
- 翻译能否读取鼠标拖动选中的文字。
- 自动写入和结果小框两种展现方式是否正常。
- 结果小框的复制、写入、替换选中、关闭、重新生成、换模型重试、继续追问和展开全文是否正常。
- 大模型返回时是否能边生成边显示；网络差或代理异常时是否有清楚提示。
- 主页功能卡片的拖动排序是否能保存。
- 录音时浮动条波形是否会随麦克风声音变化。
- 录音前倒计时和提示音开关是否按设置生效。
- 提示词编辑、锁定和各功能独立模型设置是否正常。
- 历史记录的加载、播放、复制、收藏和删除是否正常。
- 直连与使用系统代理两种网络方式是否正常。
- 历史记录保存位置能否修改，文本记录、录音记录、详细记录和总目录是否按功能与日期保存到所选位置。
- 左侧“测试诊断”里的接口自检、网络诊断、麦克风测试、浮动条测试和结果小框测试是否正常。
- 左侧“常见问题”是否能找到弹窗报错对应的解决办法。

## 反馈问题

反馈时请提供：

- 问题发生前执行的步骤。
- 实际结果和期望结果。
- 错误提示截图。
- Windows 版本以及使用的语音识别服务、模型服务。

请勿发送 `config/secrets.json`，该文件包含测试人员自行填写的接口密钥。

# Design System

## Theme

Windows 桌面效率工具。浅色内容区配深色侧栏，视觉克制，任务状态优先于装饰。

## Color

- 应用背景：`#F6F7F9`
- 内容表面：`#FFFFFF`
- 主文字：`#111827`
- 次级文字：`#667085`
- 边框：`#D0D5DD`
- 主操作：`#111827`
- 成功：`#00875A`
- 信息：`#2563EB`
- 警告与错误：`#B42318`

## Typography

- 字体：Microsoft YaHei UI
- 页面标题：24pt，DemiBold
- 区块标题：13pt，DemiBold
- 正文和表单：10pt
- 按钮文字：10pt，DemiBold
- 不使用负字距，不按窗口宽度缩放字号。

## Layout

- 主窗口最小尺寸为 1100 x 720。
- 左侧导航固定宽度，内容区自适应。
- 需要大量内容的区域使用局部滚动，不让整个窗口产生重复滚动层。
- 功能编辑、截图结果等独立窗口必须在小窗口和高 DPI 下完整显示底部操作栏。

## Components

- 卡片圆角不超过 8px，只用于单个功能、设置项和重复记录。
- 主按钮深色底，次按钮白底深色字；中文按钮最小高度 40px。
- 二元设置使用滑动开关，选项组使用下拉框或分段按钮。
- 状态包含默认、悬停、按下、禁用、处理中、成功和失败。
- 弹窗使用项目统一的 `AppDialog`；无实际帮助内容时不显示标题栏问号。

## Motion

- 开关、悬浮工具和模式切换使用 150-220ms 的平滑状态过渡。
- 截图框选跟随鼠标实时更新，不使用弹跳或装饰动画。
- 用户关闭动画或系统减少动态效果时直接切换状态。

## Screenshot OCR

- 截图时冻结当前屏幕，选区外使用半透明遮罩，选区边缘保持清晰。
- 截图工具条靠近选区但不能遮住选区，包含确认、重选和取消。
- 截图对照窗包含原图、译文覆盖和双语对照三种视图。
- 窗口透明度由用户实时调整，位置、大小和透明度自动记忆。
- RapidOCR 提供文字框时允许逐块覆盖；缺少文字框时自动使用左右对照，不显示错误。

## Command Center

- 主窗口采用命令中心结构：左侧栏负责切换主页和功能，顶部栏负责打开历史、词库、图片识别、提示词、测试、日志、设置和帮助。
- 左侧栏宽度为 176px，顶部栏高度为 52px；自定义功能只在侧栏内部滚动。
- 命令中心背景使用 `#EEF1F5`，深色导航使用 `#101827`，选中面使用 `#26344B`，信息蓝使用 `#245FC4`。
- 当前功能页只分为“输入控制”和“输出控制”两大区。语音、选中文字、截图、模型、提示词和结果方式均使用可点击展开的设置行，展开后直接显示完整配置并自动保存。
- 左侧的听写、翻译、问答和自定义功能连续排列，不使用“内置功能”“自定义功能”分组标题。
- 顶部搜索可以查找内置功能、自定义功能和主要工具页面。
- 列表刷新和页面切换使用 180ms 的 `OutCubic` 淡入，只表达状态变化，不改变布局尺寸。
- 主页“当前状态”、自定义功能导航和其它长内容区域使用局部滚动，禁止因窗口高度不足裁剪最后一行文字。

## 每个单元格的必测动作

1. 鼠标拖选、双击和键盘选择文字，确认工具栏出现规则正确且不抢焦点。
2. 复制、保存到词库、翻译、解释和 AI 搜索均使用无敏感内容的样本；拒绝确认后不得发送请求。
3. 自动写入与“替换选中”只操作原选区；选区失效后必须拒绝，不能退化成普通插入。
4. 流式、完成、错误、降级、固定和继续追问状态下检查中文长文本、按钮、下拉框、代码块和链接。
5. 检查屏幕四边、任务栏、负坐标副屏、最大化和紧凑窗口；任何文字不得裁切、重叠或超出控件。
6. 密码框、VoceKit 自身窗口、阻止名单应用和提权窗口不得泄露选中文字或错误弹窗。
7. 关闭结果、切换选区、暂停观察、锁屏或退出后，迟到结果不得覆盖新会话；剪贴板和焦点必须恢复。

## 证据记录

每次验收必须记录：

- VoceKit 版本、Git 提交、Debug/Release 和包 SHA-256；
- Windows 版本、显示器分辨率、缩放比例和主/副屏坐标；
- 代表应用的名称与版本；
- 操作步骤、实际结果、通过/失败和问题编号；
- 每个缩放档至少一张可辨识文字的截图；
- 失败修复后的复测日期与提交。

公开发布要求基础矩阵全部为“通过”，且 `docs/UPDATES.md` 中的签名、更新和回滚门槛同时通过。任何“未执行”都视为发布阻断项。

可在发布前运行 `scripts/verify-release-readiness.ps1`。该脚本会机械检查矩阵是否仍有“未执行/失败”、版本与标签、Git 同步状态、更新源公开可达性和运行目录 Authenticode 签名；它不会替代本表要求的人工真实应用操作。

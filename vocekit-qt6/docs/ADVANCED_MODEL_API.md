# 高级模型 API 控制台

VoceKit 的普通语音问答流程保持不变。只有在“设置 → 接口 → 高级 API 自定义”中明确启用某个模型的高级配置后，本页设置才参与该模型请求。

## 请求合并规则

实际发送的请求体按以下顺序生成，后面的层级优先：

1. 服务商适配器生成的基础请求，包括模型、消息、默认 Token 上限和当前流式设置。
2. “API 参数”页中的可视化参数。
3. “Raw JSON”页中的任意顶层字段。

Raw JSON 不使用固定字段白名单，因此可以直接加入软件尚未认识的厂商参数。值为 `null` 表示删除同名基础字段。完成一次调用后，右侧会显示脱敏后的最终实际请求；“将最近实际请求载入 Raw JSON”可以把它作为完整编辑起点。

Raw JSON 只控制 HTTP 请求体。API Key、认证 Header、代理和目标地址仍由接口设置管理，不接受 Raw JSON 覆盖，避免把密钥意外写入请求正文或普通日志。厂商仍可能拒绝其 API 不支持的字段，服务端原始错误会保留在调试详情中。

## System Prompt

System Prompt 与采样参数分开保存。每个内置或自定义模型配置可以维护多个提示词预设，并选择、修改、清空或删除当前预设。启用覆盖后，下次请求使用所选内容；空内容表示明确清空系统提示词。

切换模型配置前应先保存当前修改。配置文件位于程序数据目录的 `config/model_advanced.json`，不会提交到 Git。

## 模型与连接

“API 状态”页提供：

- API Key Test：执行一次不带高级覆盖的最小模型请求，验证密钥和模型名；服务商可能把它计作一次调用。
- Connection Test：使用当前已保存的高级配置，验证实际模型端点能否完成一次请求；它同样可能产生少量 Token 与费用。
- Fetch Models：请求模型列表。获取失败时仍可在可编辑模型框或 Model 覆盖字段中手动输入名称。

错误会区分认证失败、超时、限流、余额不足、服务端错误和普通连接失败，并尽量附带服务端原始信息。

## 日志、原始响应和统计

每次模型调用会向程序数据目录的 `logs/model-requests.jsonl` 追加一条 JSON Lines 日志。默认只记录不含用户正文的元数据，包括：

- 请求时间、服务商、最终模型、请求字段名和安全的标量参数；
- 消息、输入项和工具数量，不记录其正文；
- HTTP 状态码、成功状态和错误码；
- Input、Output、Total、Reasoning、Cache Hit Token（仅记录服务端实际返回的项目）；
- Finish Reason、首次响应、首 Token、总耗时；
- 原始响应字节数；
- 用户配置 Token 单价后计算的本次费用估算。

只有用户在 Request Log 页主动勾选“记录请求与响应正文”后，后续请求才额外保存脱敏后的完整请求、原始响应和错误详情。认证 Header 从不写入日志；请求和结构化响应中常见的密钥、Token、密码、Secret 字段会递归替换为 `***REDACTED***`。正文日志可能包含用户问题、系统提示词、工具定义和模型回答，开启前应确认业务隐私要求，分享前仍须人工检查。关闭开关不会自动删除已经生成的旧日志。

结果窗口默认显示 Markdown 渲染结果，可切换回可编辑原文。“原始响应 / 调试详情”提供 Rendered Response、Raw Response、Actual Request JSON、Token/Latency 和 Citations/Sources。结构化来源数据会单独显示为可点击来源卡片，不会靠伪造普通文本编号实现。

当前 Qt Widgets 渲染支持标题、粗体、斜体、列表、引用、表格、代码块、行内代码、常见代码语法配色和超链接。`$...$`、`$$...$$`、`\(...\)`、`\[...\]` 公式标记会采用数学字体和独立视觉样式，同时保留原始公式内容；项目未引入 Qt WebEngine 或在线 JavaScript 数学引擎。

## 费用估算

输入、输出和推理价格按“每一百万 Token”手动填写，币种按 USD 记录。只有 API 返回相应 Token 数量且价格已设置时才显示费用，所有费用始终标注为“估算值”。真实账单以服务商为准。

# 2026-06-26 快捷键定义去重

## 本次调整

- `voiceassistant.cpp` 不再保留内置快捷键定义副本。
- 所有内置快捷键、核心功能快捷键和截图快捷键默认值统一走 `src/input/hotkey_definitions.h/.cpp`。
- 将“根据功能快捷键推导截图快捷键”的逻辑移动到快捷键定义模块。

## 为什么拆出

快捷键属于输入层规则。之前主文件和 `hotkey_definitions` 同时保存一份定义，后续修改默认快捷键时容易出现两处不一致。
统一到一个模块后，设置页、主界面卡片、全局快捷键注册和测试都能共享同一套来源。

## 验证

- 使用 Qt 5.9 MinGW release 构建通过。

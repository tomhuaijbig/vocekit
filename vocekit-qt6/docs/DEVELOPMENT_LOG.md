# vocekit 开发日志

本文档记录项目从最初需求到当前版本的主要改动。它面向后续接手开发的人和 AI，用来快速了解“为什么现在是这样设计的”。

注意：本文只记录功能和结构，不记录真实 API Key、用户本机路径、录音内容、历史内容或任何隐私数据。

## 2026-08-17：Qt 6 成为主开发基线

- 新主开发目录为 `vocekit-qt6`；旧 `vocekit` 目录作为 Qt 5 历史版本保留。
- 工具链升级为 Qt 6.11.1、MinGW 13.1 64-bit 和 C++17。
- 完成 Qt 6 API、音频、屏幕、事件、文本编码和测试兼容性迁移。
- 182 个项目共 1816 项测试全部通过，Debug/Release、独立部署和脱离开发环境启动验证通过。
- 正式入口改为 `scripts/build.ps1`、`scripts/run-all-tests.ps1`、`scripts/deploy.ps1` 和 `scripts/package-test.ps1`。
- 本条以下的 Qt 5.9/C++11 内容均为历史记录，不再代表当前兼容性要求。

## 2026-06 初始阶段：确定产品形态

### 语音助手基础目标

- 基于 Qt 5.9 开发 Windows 桌面应用。
- 软件日常不占桌面窗口，默认后台托盘常驻。
- 使用全局快捷键触发功能。
- 至少支持听写、翻译、问答、录音保存和提示词配置。
- 支持调用百度语音识别和 DeepSeek 大模型。

### Typeless 风格交互方向

- 参考同类语音输入软件的交互方式，但不复制品牌、图标、文案和资源。
- 增加主界面、托盘菜单、浮动条、自动写入、历史记录和结果小框。
- 三个内置功能确定为：
  - 听写：语音转文字，可选是否调用模型整理。
  - 翻译：读取鼠标拖选文字后翻译。
  - 问答：读取鼠标拖选文字，可结合语音问题让模型回答。

## 2026-06 快捷键和后台运行

### 全局快捷键

- 使用 Windows `RegisterHotKey` 注册全局快捷键。
- 默认快捷键：
  - 听写：`Ctrl + Alt + Space`，后续用户改为 `Alt + X`。
  - 翻译：`Ctrl + Alt + T`，后续用户改为 `Alt + C`。
  - 问答：`Ctrl + Alt + Q`，后续用户改为 `Alt + V`。
  - 打开主界面：`Ctrl + Alt + S`。
  - 加入词库：`Ctrl + Alt + L`。
- 设置页“快捷键”中可以修改内置功能和自定义功能快捷键。
- 自定义功能新增后，也会出现在快捷键设置卡片里。

### 最近崩溃修复

- 用户反馈软件在识别或翻译英文选中文字时整个进程退出。
- 通过 Windows CrashDump 确认：
  - 崩溃模块为 `Qt5Cored.dll`。
  - 异常为 `0xc0000005`。
  - 栈路径为全局快捷键原生事件过滤器进入 `VoiceController::handleHotkey()`、`stopAndProcess()`、`finishMode()`。
- 根因：在 Windows 原生热键事件过滤器中同步执行录音停止、语音识别、大模型调用和结果写入，容易造成 Qt 事件重入和对象状态冲突。
- 修复：
  - `GlobalHotkeys::nativeEventFilter()` 只投递功能 ID 到 Qt 主事件循环，不直接执行业务。
  - `VoiceController` 增加 `m_processing` 和 `ProcessingGuard`，语音识别或模型处理期间忽略重复触发。

### 开机自启动后台启动

- 用户要求开机自启动时不要自动打开主界面。
- 自启动注册表命令改为带内部参数 `--autostart`。
- 程序启动时检测到该参数，只创建托盘、快捷键和后台服务，不调用 `hub.show()`。
- 普通双击启动不带该参数，仍按正常方式打开主界面。
- 为了兼容用户电脑上已经写入的旧启动项，`windowsAutoStartEnabled()` 仍能识别旧的不带参数命令；下一次保存设置时会自动写成新命令。

## 2026-06 接口配置

### 密钥填写方式

- 最早从本地 `1.txt` 读取开发者密钥。
- 后续删除该兼容逻辑，改为用户在软件“设置 -> 接口”里自行填写。
- 仓库只保留 `config/secrets.example.json`，不保留真实密钥。

### 语音识别接口

- 支持百度语音识别。
- 支持讯飞语音听写。
- 接口页可以选择当前语音识别服务。
- 切换语音服务后，只显示当前服务需要填写的密钥字段。
- 已填写过的另一个服务密钥仍保存在本地配置中，不会因为切换服务丢失。
- 讯飞字段顺序按官方 API 页面调整，降低填错概率。
- 百度语音识别支持粘贴百度智能云示例代码，自动解析 `client_id` 和 `client_secret`。

### 大模型接口

- 支持 DeepSeek。
- 支持 OpenAI。
- 支持 Claude。
- 模型下拉框只显示官方模型名，不写“顶级”“推荐”等主观描述。
- 每个功能都可以独立选择模型。

### 网络代理

- 默认直连，不走系统代理。
- 设置中可开启“使用系统代理”。
- 当前状态显示“直连”或“系统代理”。
- 常见问题中记录 VPN、TUN、透明代理导致 WebSocket 或 HTTPS 异常的原因和解决办法。

## 当前维护原则

- 不把真实密钥写进源码或文档。
- 不把用户录音、历史、桌面截图、本机路径提交到仓库。
- UI 文案以中文为主。
- 设置页关键操作按钮必须可见。
- 长列表要分页或滚动，不能一次性渲染过多内容。
- 新增报错必须更新常见问题编号。
- 新增配置项必须同步更新默认值、读取、保存、示例配置和测试包逻辑。
- 新增 Qt 模块后必须重新部署运行库。
- 全局快捷键不能在原生事件过滤器里同步执行重业务。

# 2026-06-26 开机自启动模块抽离

## 本次调整

- 新增 `src/platform/windows_autostart.h/.cpp`，集中处理 Windows 开机自启动。
- `voiceassistant.cpp` 不再直接维护启动项注册表路径、启动参数和启用状态判断。
- 保留原有行为：
  - 启用时写入当前用户 `Run` 启动项。
  - 启动命令带 `--autostart`，开机启动时默认不主动打开主界面。
  - 设置页、配置默认值和主程序启动流程继续复用同一套判断逻辑。

## 为什么拆出

开机自启动属于平台能力，不应该散在主界面文件里。抽离后可以减少 `voiceassistant.cpp`
对 Windows 注册表细节的直接依赖，也方便后续增加安全软件拦截提示、启动项自检和平台差异处理。

## 验证

- 使用 Qt 5.9 MinGW release 构建通过。

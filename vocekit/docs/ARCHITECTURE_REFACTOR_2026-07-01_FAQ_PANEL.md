# 架构拆分记录：常见问题页独立化

更新时间：2026-07-01

## 本轮完成

- 新增 `src/ui/faq_panel.h` 和 `src/ui/faq_panel.cpp`。
- 将常见问题页面 UI、分类筛选、搜索、问题卡片渲染、问题编号跳转和“去测试”按钮逻辑从 `HubWindow` 移到 `FaqPanel`。
- `HubWindow` 现在只保留 `FaqPanel *m_faqPanel`，并通过 `openFaqById()` 调用 `FaqPanel::showFaqId()`。
- 测试工具页不再直接读取常见问题页内部控件，而是通过 `FaqPanel::matchCount()` 获取匹配数量。
- 常见问题页点击“去测试”时，通过回调把测试工具页搜索框切到对应测试项。

## 对 11-20 架构任务的影响

- 11：继续减少 `voiceassistant.cpp` 体积，本轮从约 211 KB / 4157 行降到约 165 KB / 3537 行。
- 12：常见问题页已经变成独立 QWidget 类。当前已经独立的页面/面板包括日志页、提示词页、常见问题页、首页功能卡片、最近记录和当前状态。
- 17：常见问题页的 UI 状态和搜索逻辑从主窗口分离，`HubWindow` 的页面职责进一步降低。
- 20：FAQ 与测试工具页的联动已经通过回调和公开方法实现，后续可以继续改成事件总线或页面协调器。

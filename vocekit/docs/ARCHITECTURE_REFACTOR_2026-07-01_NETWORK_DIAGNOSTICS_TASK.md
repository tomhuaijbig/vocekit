# 架构拆分记录：网络诊断任务独立化

更新时间：2026-07-01

## 本轮完成

- 新增 `src/tasks/network_diagnostics_task.h` 和 `src/tasks/network_diagnostics_task.cpp`。
- 将测试工具页里的网络诊断业务逻辑从 `HubWindow::runNetworkDiagnostics()` 移到 `runNetworkDiagnosticsTask()`。
- 主窗口现在只负责：
  - 禁用/恢复“开始测试”按钮；
  - 读取当前是否使用系统代理；
  - 读取接口密钥配置；
  - 启动后台任务；
  - 展示诊断结果。
- 网络任务负责：
  - 软件网络模式显示；
  - Windows 系统代理检测；
  - 环境变量代理检测；
  - TUN / 虚拟网卡线索检测；
  - 常用接口域名 DNS 检查；
  - DeepSeek、百度、讯飞、OpenAI、Claude 和自定义接口连通性探测；
  - TUN / 透明代理提示。

## 对 11-20 架构任务的影响

- 13、14：测试工具页中的一个后台任务已经从 UI 类拆出，为后续功能执行管线拆分提供样板。
- 17：主窗口不再直接承载网络诊断细节，UI 与业务逻辑分离推进了一步。
- 15、16：本轮没有改变 Provider 和取消令牌；网络诊断仍是同步后台任务，后续可继续接入统一取消接口。

## 验证

- `qmake` + `mingw32-make -j2` 构建通过。
- release 下 20 个现有测试全部通过。

## 下一步建议

1. 将接口自检拆成 `InterfaceSelfCheckTask`。
2. 将麦克风测试、选中文字测试和写入测试拆为独立输入测试任务。
3. 给网络诊断任务补充可取消能力，避免网络探测较慢时无法中止。

# 2026-07-03 历史筛选逻辑拆分

## 本次改动

- 新增 `src/domain/history_filter.h/.cpp`，集中处理历史记录的“模式 + 搜索关键词 + 自定义功能”筛选。
- `hub_history_page_methods.h` 不再手写当前筛选、全部页索引、单模式列表三套循环。
- 新增 `tests/domain/history_filter_tests.cpp`，覆盖模式筛选、搜索、索引返回、收藏夹和自定义功能名称回退。

## 为什么拆分

历史页当前仍是最大的页面残留之一。筛选规则如果继续留在页面里，会导致批量删除、导出、最近记录和历史列表各自复制判断逻辑。

拆分后：

- 页面只负责传入当前标签、搜索文字和设置里的自定义功能。
- 筛选规则可以独立测试。
- 后续拆历史页 UI 时，筛选逻辑不需要再搬。

## 后续衔接

- 可以继续拆历史列表构建为独立 `HistoryListView` 或 `HistoryListBuilder`。
- 批量选择状态可以进一步拆成独立状态对象，减少 `HubWindow` 成员变量。

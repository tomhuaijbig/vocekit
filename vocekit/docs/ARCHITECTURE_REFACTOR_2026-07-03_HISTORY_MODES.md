# 2026-07-03 历史模式规则拆分

## 本次改动

- 新增 `src/domain/history_modes.h/.cpp`，集中处理历史记录的模式识别、筛选和标签生成。
- `hub_history_page_methods.h` 不再直接保存“听写/翻译/问答/图片识别/自定义功能”的匹配规则，只调用领域函数。
- `vocabulary_candidates.cpp` 复用同一套历史模式规则，避免词库候选推荐和历史页各自维护一份逻辑。
- 新增 `tests/domain/history_modes_tests.cpp`，覆盖内置模式、自定义功能、收藏夹筛选和标签生成。

## 为什么拆分

历史页仍是 `HubWindow` 中最大的残留块之一。直接搬整页风险较高，所以先拆出纯逻辑：

- 模式判断规则从 UI 方法里移到可测试模块。
- 后续历史页拆成独立 `QWidget` 时，筛选规则不用再次移动。
- 其它模块需要判断历史记录来源时，可以复用统一函数。

## 后续衔接

- 下一步可以继续拆历史列表构建、批量选择状态或历史详情弹窗。
- 如果新增内置功能，需要同时更新 `history_modes` 和对应测试，避免历史筛选、最近记录和词库候选规则不一致。

# 2026-07-03 历史展示文本拆分

## 本次改动

- 新增 `src/domain/history_text.h/.cpp`，集中处理历史记录的时间显示、标题、预览、搜索文本匹配和列表行高计算。
- `hub_history_page_methods.h` 中对应函数改为薄包装，不再保存具体拼接和计算规则。
- 新增 `tests/domain/history_text_tests.cpp`，覆盖时间格式、预览优先级、收藏/草稿/错误标题、搜索字段和行高范围。

## 为什么拆分

历史页仍然较大，直接搬 UI 风险高。先拆出纯展示规则可以降低主窗口承担的业务量：

- 列表文字规则能独立测试。
- 后续历史页成为独立页面时，文本规则无需再次搬迁。
- 搜索和预览逻辑集中后，历史页、最近记录或导出预览可以复用同一套规则。

## 后续衔接

- 可以继续拆历史列表构建和批量选择状态。
- 如果以后调整历史卡片显示文案，应优先修改 `history_text` 和对应测试。

# vocekit 测试说明

## 开始使用

1. 解压整个压缩包，不要只单独运行程序文件。
2. 双击 `vocekit.exe`。程序启动后会在系统托盘后台运行，并打开主界面。
3. 首次使用请打开“设置 -> 接口”，填写测试人员自己的接口密钥。
4. 在“设置 -> 接口”选择百度语音识别或讯飞语音听写。
5. 在“设置 -> 快捷键”查看或修改各功能快捷键。

测试包不包含开发者的接口密钥、录音和历史记录。没有填写接口密钥时，对应功能会提示配置不完整。

Windows 可能因为程序暂未签名而显示安全提醒。请确认压缩包来源可信后，再选择继续运行。

## 建议测试内容

- 程序关闭主窗口后是否仍在托盘运行，托盘菜单能否正常打开和退出。
- 听写、翻译、问答和自定义功能的快捷键是否正常。
- 翻译能否读取鼠标拖动选中的文字。
- 自动写入和结果小框两种展现方式是否正常。
- 结果小框的复制、写入、替换选中、关闭、重新生成、换模型重试、继续追问和展开全文是否正常。
- 大模型返回时是否能边生成边显示；网络差或代理异常时是否有清楚提示。
- 主页功能卡片的拖动排序是否能保存。
- 录音时浮动条波形是否会随麦克风声音变化。
- 录音前倒计时和提示音开关是否按设置生效。
- 在“功能自定义”中把某个语音功能改为“按住说话”，确认按下开始、松开结束，并且普通键盘输入不会进入日志。
- 开启长录音后连续录制 70 秒以上，确认录音不中断、浮动条显示当前段号，结束后能按顺序合并文字。
- 长录音结束后打开历史详情，确认完整录音可播放，每个分段都能单独播放或复制文字。
- 在历史详情里对失败分段点击“重试识别”，确认使用当前语音服务重试并更新记录。
- 模拟一次语音接口短暂失败，确认失败段只自动重试一次，其它成功段仍能合并。
- 如果所有分段都失败，确认不会调用大模型，并出现带常见问题编号的明确提示。
- 提示词编辑、锁定和各功能独立模型设置是否正常。
- 历史记录的加载、播放、复制、收藏和删除是否正常。
- 直连与使用系统代理两种网络方式是否正常。
- 历史记录保存位置能否修改，文本记录、录音记录、详细记录和总目录是否按功能与日期保存到所选位置。
- 左侧“测试诊断”里的接口自检、网络诊断、麦克风测试、浮动条测试和结果小框测试是否正常。
- 左侧“图片识别”能否选择 PNG、JPG、BMP 或 WebP，并在后台完成识别。
- “自动选择”在 RapidOCR 不可用时能否自动回退到 Windows OCR，且程序不会崩溃。
- 图片识别结果能否编辑、复制，并发送给智能整理、翻译、润色、总结或问答。
- 历史记录中是否出现“图片识别”标签，详情是否显示引擎、语言、耗时和回退状态。
- “测试工具 -> 接口自检 -> 当前图片识别接口”能否返回明确结果。
- 左侧“常见问题”是否能找到弹窗报错对应的解决办法。

图片识别默认在本机处理。只有测试人员主动选择“自定义云 OCR”并在确认框中同意后，图片才会发送到填写的接口地址；历史记录不会复制或保存原图片。

## 反馈问题

反馈时请提供：

- 问题发生前执行的步骤。
- 实际结果和期望结果。
- 错误提示截图。
- Windows 版本以及使用的语音识别服务、模型服务。

请勿发送 `config/secrets.json`，该文件包含测试人员自行填写的接口密钥。

## 自动测试

运行全部测试工程：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File scripts\run-all-tests.ps1
```

脚本会严格枚举 `tests` 下扩展名为 `.pro` 的工程，构建并运行 QtTest 和独立冒烟程序，最后汇总通过、失败和跳过数量。测试生成的临时 `Makefile.codex*` 会自动清理。

功能配置和结果流程使用可执行的 Qt 组件测试，不再通过 PowerShell 搜索旧主文件中的字符串：

- `hub_settings_state_tests` 验证逐功能录音参数、结果操作和持久化。
- `result_flow_tests` 验证网络策略、流式失败回退和现场恢复。
- `result_choice_popup_header_tests` 验证结果按钮配置、透明度、完成回调和取消。

录音状态机测试：

```powershell
.\build-tests\recording-red\debug\recording_core_tests.exe -txt
```

当前覆盖默认配置、范围约束、按住快捷键状态、自动重复过滤、分段顺序、单次重试、成功段计数、33 段上限和 WAV PCM 提取。

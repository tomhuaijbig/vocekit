# vocekit 输入、录音和测试工具设计

## 目标

完善输入测试、麦克风样本、浮动条状态测试、按住说话和长录音分段，同时保持现有点击快捷键开始/再次点击结束的模式。

## 测试工具

### 选中文字测试

- 点击“开始测试”后等待用户在其它程序中选中文字。
- 测试窗口临时隐藏 5 秒，倒计时结束后读取当前选中文字。
- 分别显示普通读取结果和强力选中结果。
- 不自动复制结果，不调用 AI。
- 强力选中前明确标注可能触发安全软件提醒。

### 写入测试

- 页面提供内置多行文本框和一段默认测试文字。
- 支持测试“写入当前光标”和“替换选中”。
- 只在 vocekit 自己的测试文本框中执行，不向其它程序写入，避免误操作。
- 测试后显示剪贴板恢复是否成功。

### 麦克风测试保存样本

- 默认录制 3 秒。
- 增加“保留测试样本”开关。
- 关闭时使用临时目录并在测试后删除。
- 开启时保存到历史根目录的“测试样本/麦克风/YYYY-MM-DD”。
- 测试结果显示峰值、平均音量、是否削波和保存路径。

### 浮动条状态测试

状态下拉：

- 准备录音。
- 录音中。
- 识别中。
- 模型处理中。
- 写入中。
- 完成。
- 失败。

录音中状态运行模拟波形，其它状态显示阶段名称和累计耗时。测试不调用麦克风、语音接口或大模型。

## 按住说话

每个使用语音输入的功能增加录音触发方式：

- 切换模式：按一次开始，再按一次结束。
- 按住说话：按下快捷键开始，松开快捷键结束。

默认保持现有切换模式。

Windows `RegisterHotKey` 只能报告完整按键触发，不能可靠报告松开。因此按住说话需要新增低级键盘钩子，只监听用户已经配置的快捷键组合。

安全要求：

- 钩子回调只记录按下、松开和时间，不执行录音、网络或 UI 重业务。
- 实际开始和停止通过 Qt 事件队列异步执行。
- 不记录普通键盘输入，不写入日志具体字符。
- 软件退出或设置变更时必须卸载钩子。
- 快捷键冲突或钩子安装失败时自动回退切换模式并提示原因。

## 分段长录音

### 行为

- 功能配置增加“允许长录音”开关。
- 关闭时保持当前 60 秒自动结束。
- 开启时每段最长 55 秒，预留结束和切换缓冲。
- 一段结束后立即开始下一段录音，录音间隔目标小于 200 毫秒。
- 已完成的段在后台排队识别，用户继续录下一段。
- 用户结束录音后等待所有段识别完成，再按段号合并文本。

### 状态

浮动条显示：

- 正在录音：总时长和当前段号。
- 正在识别第 N 段。
- 等待 N 个识别任务。
- 正在合并。
- 正在调用模型。

### 顺序和并发

- 录音始终只有一个当前段。
- 语音识别默认串行，避免百度或讯飞接口被大量并发请求。
- 每段带连续序号，返回顺序不影响最终合并顺序。
- 同一任务最多 30 分钟或 33 段，达到上限后自动结束。

### 失败处理

- 某段失败时自动重试一次。
- 重试仍失败时保留其它段，合并文本中插入 `[第 N 段识别失败]`。
- 最终结果小框显示失败段数量并允许重新识别失败段。
- 全部分段失败时不调用大模型，显示明确错误。
- 用户取消时停止当前录音和未开始的识别任务，已完成结果保存为草稿。

### 文件

录音目录：

```text
历史记录/
  功能分类/
    YYYY-MM-DD/
      录音记录/
        任务时间_完整.wav
        任务时间_分段/
          segment_001.wav
          segment_002.wav
```

最终完整 WAV 在后台合并生成。分段文件默认保留，历史详情可以逐段播放。

## 数据结构

功能配置新增：

```json
{
  "recordingTriggerMode": "toggle",
  "longRecordingEnabled": false,
  "segmentSeconds": 55,
  "maxRecordingMinutes": 30
}
```

历史详情新增：

```json
{
  "recordingTriggerMode": "hold",
  "segmentCount": 3,
  "failedSegments": [2],
  "segments": [
    {
      "index": 1,
      "audio": "segment_001.wav",
      "text": "第一段",
      "elapsedMs": 1200,
      "error": ""
    }
  ]
}
```

## 模块边界

新增：

- `src/modules/hold_to_talk.h/.cpp`：低级键盘钩子和按下/松开事件。
- `src/modules/segmented_recording.h/.cpp`：分段状态机、队列、重试和合并。
- `src/modules/hub_input_tests.inc`：选中文字和写入测试组件。

调整：

- `src/modules/audio_recorder.inc`：支持明确结束当前段，不负责识别和排队。
- `src/modules/floating_bar.inc`：阶段、段号、总耗时和模拟状态。
- `src/modules/settings_panel.inc`：全局录音设置。
- 功能编辑弹窗：每个功能独立录音触发方式和长录音开关。
- `src/modules/hub_history_page.inc`：分段录音详情。
- `src/voiceassistant.cpp`：只负责连接控制器和页面，不实现分段算法。

## 常见问题

至少新增：

1. 按住说话键盘钩子安装失败。
2. 按住说话被安全软件阻止。
3. 松开快捷键后仍在录音。
4. 长录音分段切换失败。
5. 某一段识别失败。
6. 完整 WAV 合并失败。
7. 麦克风测试样本无法保存。
8. 写入测试无法恢复剪贴板。
9. 选中文字测试读取为空。

## 验收

- 切换模式行为和当前版本一致。
- 按住说话按下开始、松开结束，不记录其它键盘输入。
- 录音超过 60 秒时可以继续，段落按顺序合并。
- 其中一段失败不会丢失其它成功段。
- 主界面在录音和识别期间保持响应。
- 麦克风测试样本按用户选择保存或删除。
- 浮动条可以独立预览所有状态。
- 选中文字和写入测试不会调用外部接口。

# vocekit 命令中心主窗口设计规格

## 目标

把现有主窗口重组为命令中心布局，使听写、翻译、问答和自定义功能成为左侧的主要工作入口，把历史记录、词库、图片识别、提示词、测试工具、日志和设置集中到顶部工具栏。保留现有业务功能、配置文件和快捷键行为。

## 信息架构

### 左侧功能栏

- 固定显示：主页、听写、翻译、问答。
- 听写、翻译、问答和自定义功能在同一个局部滚动列表连续显示，不增加分组标题。
- 底部显示“新增功能”。
- 当前功能使用深色选中底和左侧蓝色状态线。
- 自定义功能增删或刷新时使用短时淡入，不使用弹跳和装饰动画。

### 顶部工具栏

- 左侧为全局搜索框。
- 右侧依次为：历史、词库、图片识别、提示词、测试、日志、设置。
- 常见问题通过顶部帮助按钮进入。
- 工具页被打开时，顶部对应按钮显示选中状态。
- 搜索框根据当前页面执行搜索；主页和功能页用于查找入口并跳转。

### 中央工作区

- 主页保留功能概览、最近记录和当前状态，但统一采用命令中心间距和控件样式。
- 功能入口直接打开对应功能的内嵌配置页。
- 每个功能页只分为“输入控制”和“输出控制”两大区；设置行点击后展开完整配置并直接保存。
- 工具入口继续使用现有历史、词库、OCR、提示词、测试、日志和设置页面。
- 页面背景、标题、输入框、列表、滚动区域和空状态统一。

## 视觉规则

- 左侧栏和顶部栏：`#101827`。
- 左侧选中面：`#26344B`。
- 应用背景：`#EEF1F5`。
- 内容面：`#FFFFFF`。
- 边线：`#D7DEE9`。
- 主文字：`#101828`。
- 次要文字：`#687386`。
- 信息蓝：`#245FC4`。
- 圆角不超过 8px。
- 使用 Microsoft YaHei UI。
- 不使用渐变、玻璃效果、装饰性阴影和持续动画。

## 动效规则

- 列表刷新和页面切换使用 160-200ms 的淡入。
- 按钮悬停和选中状态立即响应或使用不超过 180ms 的颜色过渡。
- 系统减少动态效果时直接切换。
- 动效不得改变控件最终尺寸，避免布局抖动。

## 响应式与可用性

- 主窗口最小尺寸保持 1100 x 720。
- 侧栏固定约 176px，顶部栏固定约 52px。
- 自定义功能仅在侧栏内部滚动，不让整个主窗口产生第二层滚动。
- 所有中文标签在 125% 和 150% 缩放下必须完整显示。
- 顶部工具按钮宽度不足时允许工具区横向滚动，不裁剪文字。

## 非目标

- 不引入 React、WebView 或 React Bits 运行时。
- 不改变 API、录音、OCR、历史记录和快捷键的业务逻辑。
- 不实现参考网页中当前软件没有的数据字段。
- 不复制第三方品牌、图标或文案。

## 验收

- 左侧功能入口和顶部工具入口均能打开正确页面。
- 听写、翻译、问答、自定义功能仍可编辑和保存。
- 历史、词库、图片识别、提示词、测试、日志、设置、常见问题功能不回退。
- 小窗和全屏状态下没有文字裁剪、重叠或无效滚动区域。
- Qt 5.9 MinGW Debug 和 Release 均可编译。
